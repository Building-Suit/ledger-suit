لم يُفترض معدل ضريبة ساري أو إلزام جميع المنشآت بتاريخ واحد، ولم تُستخدم أسماء الحسابات في الإكسيل باعتبارها معيارًا محاسبيًا. أمثلة الأرقام والشجرة وقواعد منع التكرار وأسلوب العكس ومراحل التنفيذ مقترحات أصلية لهذه الخطة، وتُختبر وتُعتمد بحسب نطاق المنتج.

## قرارات مسجلة لهذه النسخة

| القرار | حالته |
|---|---|
| استبدال ترتيب الخطة القديمة بخطة محاسبية أولًا | طلب صريح من المؤسس |
| فصل العربية والإنجليزية في النصوص والقوالب والعرض | طلب صريح من المؤسس |
| اليومية الموحدة والمراجعة المترابطة وحفظ السياق | طلب صريح من المؤسس |
| نطاق خدمات وتجارة صغيرة ومتوسطة في مصر | افتراض عمل معلن ينتظر تأكيد المستخدم |
| شجرة القالب والسياسات والدفاتر المطلوبة | مقترح للمحاسب؛ لا اعتماد مسجل |
| جرد مستمر ومتوسط متحرك في القالب التجاري | مقترح يحتاج موافقة حسب النشاط |
| تفاصيل التحول منتصف السنة والاعتماد وإعادة الفتح | تُحسم بإجابات وثيقة المحاسب |
| الأسعار والاشتراكات القائمة وحماية البيانات | محفوظة؛ لا تغيير تجاري أو مالي ضمن إعداد الخطة |
| طلب الدمج ٩٦ | مفتوح وقت الفحص؛ لا يُعد موافقة على النموذج الجديد ولا يُدمج تلقائيًا |

تحديث هذه القرارات بعد الرد يذكر صاحب القرار وتاريخه وسببه والوثائق والاختبارات المتأثرة. لا تُحوّل أسئلة غير مجابة إلى موافقات.
