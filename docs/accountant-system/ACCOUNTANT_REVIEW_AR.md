# وثيقة مراجعة النظام المحاسبي

نسخة للمحاسب — ١٨ سبتمبر ٢٠٢٦

الغرض: مراجعة تصور نظام محاسبي عبر الإنترنت قبل تنفيذ تعديلاته المالية. هذه مواصفات مقترحة للمراجعة وليست وصفًا بأن كل الوظائف موجودة حاليًا. المطلوب تصحيح أي معالجة أو استكمال أي دورة ناقصة، مع مثال للمستند والقيد والتقرير المتوقع.

## ١. النطاق وطريقة العمل

نفترض مبدئيًا منشأة خدمات أو تجارة صغيرة أو متوسطة في مصر، على أساس الاستحقاق. يؤكد المحاسب النشاط والبلد والإطار المحاسبي والسنة المالية والعملة الأساسية والحالة الضريبية. كل منشأة لها دفاتر وصلاحيات مستقلة. الصناعات والمقاولات والتجميع بين الشركات تحتاج حزمًا متخصصة قبل الادعاء بدعمها.

إدخال المستند مرة واحدة يربطه بالقيد والأستاذ والمساعد والتقارير. فاتورة البيع تختلف عن التحصيل، وفاتورة الشراء تختلف عن السداد. الدفعات المقدمة ليست إيرادًا أو مصروفًا تلقائيًا. تتوازن القيود على مستوى كل عملية، وتبقى المستندات والأطراف والتواريخ قابلة للتتبع.

اللغة العربية تعرض مصطلحات عربية فقط، والإنجليزية تعرض مصطلحاتها المقابلة فقط. لا نكتب اسم الحساب باللغتين في نفس الخانة. الاسم الذي يدخله المستخدم يُحفظ كما هو، ويمكن إضافة ترجمة مستقلة باختياره.

## ٢. المصطلحات التي تظهر للمحاسب

| المصطلح | المعنى داخل النظام |
|---|---|
| دليل الحسابات أو شجرة الحسابات | تنظيم الحسابات وتصنيفها وعلاقتها بالقوائم |
| حساب تجميعي | عنوان يجمع حسابات تحته ولا يقبل الترحيل المباشر |
| حساب ترحيل | حساب تفصيلي تُسجل عليه بنود القيد |
| حساب مراقبة | حساب أستاذ تقابله تفاصيل دفتر مساعد تُطابق معه |
| طبيعة الرصيد | الجانب المعتاد للحساب؛ لا تمنع رصيدًا فعليًا مخالفًا |
| الحساب المقابل | حساب يخفض بندًا مرتبطًا مثل مجمع الإهلاك مقابل الأصل |
| قيد يومية | عملية متوازنة من بندين أو أكثر |
| سند قبض أو صرف | مستند تحصيل أو سداد ينتج قيدًا، وليس دائمًا إيرادًا أو مصروفًا |
| دفتر الأستاذ | حركة حساب مع رصيده الافتتاحي ورصيده المتراكم |
| دفتر مساعد | تفاصيل العملاء أو الموردين أو الأصول أو المخزون التي تطابق الأستاذ |
| ترحيل | اعتماد الأثر المحاسبي للقيد في الدفاتر والتقارير |
| عكس وتسوية | تصحيح موثق مرتبط بالأصل دون محو سجل العملية |
| ميزان مراجعة | أرصدة افتتاحية وحركة وأرصدة ختامية، كل منها مدين ودائن |
| تاريخ المستند وتاريخ القيد | تاريخ المصدر وتاريخ الاعتراف المحاسبي؛ قد يختلفان مع سبب |

لا تُستخدم «من» و«إلى» وحدهما في النماذج. عند صرف مصروف: «حساب المصروف — مدين» و«حساب السداد — دائن». عند تحصيل مديونية: «حساب التحصيل — مدين» و«العميل — دائن». يظهر القيد المتوقع قبل الترحيل.

## ٣. دليل الحسابات المقترح

الأكواد التالية مقترحة لتنظيم قالب الخدمات والتجارة، وليست ترقيمًا إلزاميًا في معايير المحاسبة. الفروع الجامعة لا تقبل قيدًا؛ الحسابات التفصيلية تُنشأ تحتها حسب المنشأة. «متداول» و«غير متداول» يخضعان لظروف الاستحقاق والسياسة؛ الأصول الثابتة جزء من الأصول غير المتداولة وليست كلّها.

هذه الشجرة لا تفتح كل الفروع لكل عميل. حقوق استخدام الأصول والتزامات الإيجار، والأدوات المالية والضرائب المؤجلة تتطلب معالجة متخصصة عند انطباقها، ولا يكفي إنشاء اسم حساب لإعلان دعمها. الأرض لا يُفرض عليها جدول إهلاك تلقائي كالمباني. جاري الشركاء والأرصدة المخالفة لطبيعتها لا تُصنف بالاسم وحده.

مراجعة مطلوبة: ما الحسابات الناقصة لنشاطك؟ ما الحسابات غير اللازمة؟ هل نحتاج فروعًا أو مشروعات أو مراكز تكلفة؟ ما حسابات المراقبة التي يجب منع القيود اليدوية عليها إلا بتسوية مرتبطة بتفاصيل مساعد؟

## ٤. إنشاء الحساب والبداية الصحيحة

إنشاء حساب يحدد الاسم والكود والأب والتصنيف ونوع العقدة والطبيعة والعملة وبند القوائم. يُقترح الجانب المعتاد تلقائيًا مع اختيار معتمد للحسابات المقابلة. الرصيد الفعلي قد يكون مدينًا أو دائنًا دون تبديل الطبيعة. إنشاء حساب من داخل مستند يعيده مختارًا فورًا، ويحفظ باقي البنود.

يظهر خيار الرصيد الافتتاحي مع التاريخ والجانب والعملة والسعر، ويتحول إلى قيد افتتاحي مرتبط. استيراد بداية المنشأة يشمل ميزانًا متوازنًا وتفاصيل ذمم ومخزون وأصول مطابقة له. لا يختفي فرق الافتتاح داخل حقوق الملكية بصمت. إضافة حساب بعد بدء العمل لا تعني حق إدخال رصيد قديم خارج مراجعة التحول.

في بداية السنة تحمل أرصدة الميزانية المعتمدة. في منتصف السنة نحدد هل سنستورد الحركات منذ أول السنة أم أرصدة مجمعة مع نتيجة الفترة وتفاصيلها المتاحة، مع منع ازدواج الإيرادات أو المصروفات. يختار المحاسب تاريخ القطع وطريقة المطابقة ومصدر الاعتماد.

## ٥. أمثلة القيود المطلوبة

الأمثلة تعليمية افتراضية بوحدة نقد واحدة، دون ضرائب إلا المثال الضريبي. تفترض تحقق شروط الاعتراف ووجود المستند؛ لا تحدد معالجة كل عقد أو حالة قانونية.

| العملية | الطرف المدين | الطرف الدائن |
|---|---|---|
| مصروف إيجار نقدي ١٬٠٠٠ | مصروف إيجار ١٬٠٠٠ | خزينة ١٬٠٠٠ |
| خدمة منفذة على الحساب ١٠٬٠٠٠ | عملاء ١٠٬٠٠٠ | إيراد خدمات ١٠٬٠٠٠ |
| تحصيل جزئي من العميل ٤٬٠٠٠ | بنك ٤٬٠٠٠ | عملاء ٤٬٠٠٠ |
| مقدم من عميل ٣٬٠٠٠ قبل التنفيذ | بنك ٣٬٠٠٠ | دفعات مقدمة من عملاء ٣٬٠٠٠ |
| تحقق إيراد المقدم بعد التنفيذ | دفعات مقدمة من عملاء ٣٬٠٠٠ | إيراد خدمات ٣٬٠٠٠ |
| شراء بضاعة آجلًا ٨٬٠٠٠ بالجرد المستمر | مخزون ٨٬٠٠٠ | موردون ٨٬٠٠٠ |
| سداد المورد ٥٬٠٠٠ | موردون ٥٬٠٠٠ | بنك ٥٬٠٠٠ |
| بيع البضاعة ١٢٬٠٠٠ وتكلفتها ٨٬٠٠٠ | عملاء ١٢٬٠٠٠؛ تكلفة مبيعات ٨٬٠٠٠ | مبيعات ١٢٬٠٠٠؛ مخزون ٨٬٠٠٠ |
| تحويل بين بنك وخزينة ٢٬٠٠٠ | خزينة ٢٬٠٠٠ | بنك ٢٬٠٠٠ |
| شراء جهاز جاهز للاستخدام ٢٤٬٠٠٠ | أجهزة ٢٤٬٠٠٠ | بنك ٢٤٬٠٠٠ |
| إهلاك شهر ١٬٠٠٠ وفق جدول معتمد | مصروف إهلاك ١٬٠٠٠ | مجمع إهلاك أجهزة ١٬٠٠٠ |
| خدمة مستحقة لم تُسدد ٢٬٠٠٠ | مصروف خدمة ٢٬٠٠٠ | مصروفات مستحقة ٢٬٠٠٠ |
| سداد المستحق في الشهر التالي | مصروفات مستحقة ٢٬٠٠٠ | بنك ٢٬٠٠٠ |
| اشتراك سنة مقدم ١٢٬٠٠٠ | مصروفات مقدمة ١٢٬٠٠٠ | بنك ١٢٬٠٠٠ |
| تحميل شهر من الاشتراك ١٬٠٠٠ | مصروف اشتراك ١٬٠٠٠ | مصروفات مقدمة ١٬٠٠٠ |
| أصل قرض ١٠٬٠٠٠ مع فائدة ٥٠٠ عند السداد | قرض ١٠٬٠٠٠؛ مصروف فائدة ٥٠٠ إذا لم يسبق إثباتها | بنك ١٠٬٥٠٠ |

مثال ضريبي حسابي فقط: فاتورة أساسها ١٬٠٠٠ وضريبتها الافتراضية ١٠٠؛ يُثبت العميل مدينًا ١٬١٠٠، والإيراد دائنًا ١٬٠٠٠، وضريبة المخرجات دائنة ١٠٠. ليست هذه نسبة ضريبية مقترحة أو إقرارًا بخضوع العملية. يحدد المحاسب نسب وأنواع الضرائب والخصم وقابلية استرداد المدخلات حسب المنشأة وتاريخ المستند.

عند المرتجع يُربط الإشعار بالفاتورة وتُعكس الآثار المناسبة، وتعود البضاعة وتكلفتها عند استلامها فعليًا وفق سياستها. عند بيع أصل تُستبعد تكلفته ومجمعه ويظهر الفرق ربحًا أو خسارة، ولا تُعتبر كل المتحصلات ربحًا. إذا كانت الفائدة مثبتة قبل السداد يُسدد حساب المستحق بدل تكرار المصروف.

## ٦. المستندات والدفاتر المساعدة

دورة العميل: تنفيذ أو تسليم، فاتورة، تحصيل، تخصيص، إشعار تعديل، كشف وأعمار. دورة المورد: استلام، فاتورة، سداد، تخصيص، مرتجع، كشف وأعمار. تاريخ الاستحقاق والتسويات اللاحقة محفوظان حتى يمكن استخراج الرصيد في تاريخ سابق. لا يُسجل التحصيل إيرادًا مرة أخرى.

أرصدة العملاء والموردين المفصلة تطابق حسابات المراقبة. يُسمح بتحصيل أو دفع غير مخصص، ويظهر منفصلًا إلى أن يُخصص. طرف واحد يمكن أن يكون عميلًا وموردًا، دون مقاصة تلقائية. من كل رصيد يمكن فتح الفواتير والتسويات والمستندات.

المخزون يحتاج كمية وقيمة وحركة ومخزن وتكلفة بيع وجرد ومرتجعات، وليس حسابًا اسمه مخزون فقط. يُقترح الجرد المستمر والمتوسط المتحرك للنشاط التجاري بعد المراجعة. لا تُسمح كميات سالبة افتراضيًا، وتحتاج الحركات بأثر سابق معالجة تكلفة محكومة.

الأصل يحتاج بطاقة وجدول إهلاك وحالة جاهزية واستبعاد. البنوك تحتاج كشفًا وتسوية مع بنود معلقة؛ مطابقة سطر بنك بقيد قائم لا تنشئ قيدًا ثانيًا. الشيكات وأوراق القبض والدفع لها حالات تتحرك حتى التحصيل أو الصرف أو الارتداد.

## ٧. مكان واحد للعمل والمراجعة

مركز اليومية يجمع القيود الناتجة من كل المستندات، مع فلاتر التاريخ والنوع والحالة والحساب والطرف والمشروع. إضافة قيد مركب متاحة بجانب نماذج القبض والصرف والفواتير. تظهر إجماليات المدين والدائن والفرق ومعاينة الأثر قبل الترحيل.

الضغط على اسم حساب داخل قيد يفتح لوحة فيها بياناته ورصيده وحركاته ورابط كشفه. من اللوحة يمكن فتح مستند أو طرف ثم الرجوع دون ضياع القيد أو المسودة أو موضع التمرير والفلاتر. التقرير يتيح الوصول من الإجمالي إلى البند ثم المستند. لكل مستخدم الشركة الحالية واضحة دائمًا.

القيود تمر بمسودة ثم مراجعة عند تفعيلها ثم ترحيل. بعد الترحيل يكون التصحيح بعكس أو تسوية مرتبطين بالأصل مع سبب وهوية المنفذ. إلغاء مستند غير مرحل يختلف عن عكس قيد مرحل. رقم العملية يبقى قابلًا للتتبع ولا يُعاد استخدامه لإخفاء إلغاء.

## ٨. التقارير والإقفال

المطلوب: يومية عامة، أستاذ، ميزان مراجعة افتتاحي وحركة وختامي، دخل للفترة، مركز مالي في تاريخ، تدفقات نقدية، تغيرات حقوق ملكية، وكشوف وأعمار العملاء والموردين، ومخزون وأصول وضرائب وتسويات بنوك. المقارنات والإيضاحات تُجهز حسب الإطار المطلوب. التقارير تدعم الطباعة والتصدير بلغة واحدة مع اسم المنشأة والفترة والعملة.

اختبارات المطابقة: مجموع المدين يساوي الدائن؛ الافتتاح مع صافي الحركة يساوي الختام؛ المساعد يساوي الأستاذ؛ المخزون والأصول يطابقان حساباتهما؛ المركز المالي متوازن؛ نتيجة الدخل تظهر مرة واحدة في حقوق الملكية؛ النقد الافتتاحي مع حركته وأثر العملة المناسب يساوي النقد الختامي.

قبل قفل الشهر تُراجع البنوك والذمم والجرد والأصول والمستحقات والمقدمات والضرائب. إقفال السنة ينقل نتيجة الفترة للأرباح المحتجزة دون تكرارها أو إعادة نسخ أرصدة الميزانية في دفتر مستمر. إعادة الفتح تحتاج صلاحية وسببًا واعتمادًا. لا تقبل الفترة المقفلة قيدًا جديدًا أو عكسًا بتاريخها دون المسار المعتمد.

## ٩. أسئلة الاعتماد

يكتب المحاسب أمام كل بند: موافق، يحتاج تعديلًا، أو غير منطبق؛ مع السبب والمثال. عدم الرد ليس موافقة. يمكن إرفاق نموذج مستند منزوع البيانات الشخصية لتوضيح دورة غير مغطاة.

| رقم | القرار المطلوب | الإجابة أو التعديل |
|---|---|---|
| ١ | ما النشاط والبلد والشكل القانوني والإطار المحاسبي؟ | يُستكمل بالمراجعة |
| ٢ | ما بداية السنة المالية والعملة الأساسية وتاريخ التحول؟ | يُستكمل بالمراجعة |
| ٣ | هل الشجرة تغطي النشاط؟ ما الحسابات التي تُضاف أو تُحذف؟ | يُستكمل بالمراجعة |
| ٤ | هل توجد أرصدة قديمة على حسابات تجميعية؟ كيف تُنقل مع حفظ التاريخ؟ | يُستكمل بالمراجعة |
| ٥ | هل التحول بداية سنة أم منتصفها؟ ما مستوى التاريخ المطلوب استيراده؟ | يُستكمل بالمراجعة |
| ٦ | ما سياسة الاعتراف بالخدمات والمقدمات والمرتجعات؟ | يُستكمل بالمراجعة |
| ٧ | هل الجرد المستمر والمتوسط المتحرك مناسبان؟ هل توجد دفعات أو صلاحية أو أرقام مسلسلة؟ | يُستكمل بالمراجعة |
| ٨ | ما سياسة الإهلاك والرسملة والقيمة التخريدية ومراجعة العمر؟ | يُستكمل بالمراجعة |
| ٩ | ما الضرائب والخصم والاستقطاع والتكاملات الإلكترونية المنطبقة؟ | يُستكمل بالمراجعة |
| ١٠ | هل تحتاج معاملات أجنبية أو إعادة تقييم أو قيود تمويل أو إيجار متخصصة؟ | يُستكمل بالمراجعة |
| ١١ | ما الأدوار وحدود الاعتماد وسياسة القفل وإعادة الفتح والتصحيح؟ | يُستكمل بالمراجعة |
| ١٢ | ما تقارير الإدارة والفروع ومراكز التكلفة المطلوبة؟ | يُستكمل بالمراجعة |
| ١٣ | هل مسار فتح الحساب والرجوع للقيد يطابق طريقة المراجعة اليومية؟ | يُستكمل بالمراجعة |
| ١٤ | ما العملية المحاسبية التي لا يغطيها التصور؟ اذكر مستندًا وقيدًا وتقريرًا متوقعًا. | يُستكمل بالمراجعة |

اسم المراجع وصفته: يضافان عند المراجعة. تاريخ المراجعة ورقم نسخة الوثيقة: يثبتان عند الرد. حالة الاعتماد الحالية: لم يُعتمد بعد. نجاح أي اختبار برمجي لا يحل محل مراجعة المعالجة المحاسبية.

## ١٠. أساس البحث وحدوده

الملف المرسل يحتوي يومية ودليلًا وميزانًا وقوائم وتقارير عملاء وموردين. استُخدم لفهم طريقة العمل، ولم تُنقل صِيَغه باعتبارها قواعد نهائية؛ بيانات اليومية الفعلية فيه غير مُعبأة، وبعض نطاقات وصيغ التقارير تحتاج مراجعة. النظام الحالي يحتوي أساس قيد مزدوج يمكن تطويره، لكنه لا يحقق كل المواصفات الواردة هنا بعد.

المبادئ المهنية جرى الرجوع فيها إلى [شرح جمعية المحاسبين القانونيين المعتمدين للقيد والمعادلة](https://www.accaglobal.com/gb/en/student/exam-support-resources/foundation-level-study-resources/fa1/technical-articles/accounting-equation.html)، و[المخزون](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/)، و[الأصول](https://www.ifrs.org/issued-standards/list-of-standards/ias-16-property-plant-and-equipment/)، و[التدفقات النقدية](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/). تحديد الإطار المحلي يستند إلى [مرجع المعايير المصرية](https://fra.gov.eg/معايير-المحاسبةومراقبي-الحسابات/)، والتكامل الضريبي إلى [مصلحة الضرائب المصرية](https://sdk.invoicing.eta.gov.eg/). تاريخ الاطلاع: ١٨ سبتمبر ٢٠٢٦. تصميم النظام لا يشكل بمفرده إقرار امتثال لكل المعايير أو تشريعات كل منشأة.
