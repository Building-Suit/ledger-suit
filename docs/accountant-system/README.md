# خطة النظام المحاسبي للمحاسبين

التاريخ: ١٨ سبتمبر ٢٠٢٦. الحالة: خطة جديدة للمراجعة، وليست شهادة اكتمال أو اعتماد محاسبي.

هذه هي نقطة الدخول الوحيدة للتخطيط الحالي. ألغى طلب المؤسس الأخير ترتيب الخطة السابقة وأولوية تحسين الشاشات قبل اكتمال دورة المحاسبة. لا يُستأنف ترتيب حزم العمل أو مراحل الواجهة القديمة تلقائيًا.

1. [الخطة الرئيسية](MASTER_PLAN_AR.md): نطاق المنتج، القواعد، دورات العمل، التنفيذ، وشروط الإطلاق.
2. [وثيقة مراجعة المحاسب](ACCOUNTANT_REVIEW_AR.md): الشجرة المقترحة، المصطلحات، القيود، والأسئلة المطلوب اعتمادها. تتوفر [نسخة Word عربية قابلة للإرسال](deliverables/Accountant_Review_AR.docx) من ١٠ صفحات.
3. [مراجعة الإكسيل والكود](EVIDENCE_AR.md): ما لوحظ فعليًا، وما ينقص، وما لم يُتحقق منه.
4. [سيناريوهات القبول](ACCEPTANCE_AR.md): أمثلة رقمية ومطابقات تُختبر قبل اعتماد المنتج.
5. [المراجع](SOURCES_AR.md): مصادر مهنية ورسمية وروابطها وتاريخ الاطلاع.

اللغة العربية مستقلة عن الإنجليزية في الواجهة، وأسماء القوالب، والبيانات التجريبية، والتقارير. الإشارات الإنجليزية في ملحق الأدلة هي أسماء ملفات ودوال فعلية لتسهيل التحقق، وليست نصوصًا مقترحة للمستخدم.

محتوى الخطط السابقة محفوظ في تاريخ المستودع عند الالتزام `6fb152ee72e2b6b22269230917b2f9237fc2612d`. الملفات القديمة أصبحت إحالات إلى هذه الخطة؛ لا تحمل موافقات أو ترتيب تنفيذ نافذًا. تظل حماية البيانات وعزل الشركات والسياسات التجارية الموجودة متطلبات قائمة، وتُنقل مخاطرها إلى الخطة الجديدة.

لم يُعدل التطبيق أو دفتر الأستاذ أو قاعدة بيانات أثناء إعداد هذه الوثائق. طلب دمج الواجهة [رقم ٩٦](https://github.com/Building-Suit/ledger-suit/pull/96) كان مفتوحًا وقت المراجعة، وليس جزءًا من خط الأساس المعتمد هنا؛ نجاح اختباراته السابقة لا يعني اعتماد المحاسب أو قبول خلط اللغات في أمثلته.

التحقق من هذه الحزمة: فحص الروابط المحلية، ومراجعة بصمة المصنف دون تغيير، وحساب مستقل لأمثلة القيود والميزان والربح والمركز المالي والتدفقات والمخزون. جرى تحويل وثيقة المراجعة إلى صفحات ومعاينة صفحاتها العشر، بما فيها اتجاه العربية والجداول والروابط. لم تُستخدم اختبارات التطبيق لإثبات وظائف مقترحة لم تُنفذ بعد.
